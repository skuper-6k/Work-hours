РАБОЧИЕ ЧАСЫ v3 — GitHub Pages

Файлы готовы для загрузки в корень репозитория GitHub Pages.

Что внутри:
- index.html — приложение
- manifest.webmanifest — установка на экран Домой
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки
- robots.txt — запрет индексации

Обновление существующего сайта:
1. Открой репозиторий GitHub.
2. Add file -> Upload files.
3. Перетащи все файлы из этой папки.
4. Подтверди замену index.html / manifest.webmanifest / sw.js / icons.
5. Commit changes.
6. Подожди 1–3 минуты.
7. Открой сайт и обнови страницу.
8. На iPhone при необходимости удали старую иконку с Home Screen и добавь сайт заново.

Данные пользователя хранятся локально на устройстве в localStorage.
GitHub не получает введённые рабочие часы.
Рекомендуется периодически использовать Экспорт JSON.
